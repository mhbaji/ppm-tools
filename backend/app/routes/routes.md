# Pemisahan rute

- `pages.py` mendaftarkan halaman aktif dan aset frontend; URL yang sudah dipakai klien tetap dipertahankan.
- `public.py` berisi route API untuk tahun, subunit, tahapan, tagging, anggaran, perbandingan, realisasi publik, direktori tautan, dan pembuatan shortlink. Blueprint `shortlink_redirect` pada modul yang sama mendaftarkan redirect publik `/s/<alias>` tanpa prefix API.
- `admin.py` berisi route autentikasi serta pengelolaan data admin, topik, dan tautan.
- `admin_helpers.py` menampung validasi, impor, query, dan serialisasi khusus admin.
- `public_helpers.py` menampung query, hierarki, dan utilitas ekspor untuk route publik.
- `common.py` menyediakan validasi, autentikasi, pembentukan hierarki, dan handler error bersama.
- Modul route dan helper memiliki docstring tujuan; fungsi route/helper menjelaskan maksudnya.
- Halaman dan endpoint Dinamisasi Anggaran tidak didaftarkan.
- `/realisasi` menyajikan halaman publik realisasi; `GET /api/realisasi/periods` dan `GET /api/realisasi` mengembalikan periode/data yang difilter tahun, periode, subunit, pencarian, pagination, dan sorting. Tambahkan `format=excel` pada `/api/realisasi` untuk ekspor seluruh hasil terfilter di server.
- `GET /api/sub-units` mengembalikan subunit untuk tahun terpilih. Filter ekspor Dashboard dan Tagging mengirim `skpd_code` berulang; tanpa pilihan, semua subunit disertakan.
- `GET /api/anggaran` menyediakan hierarki Dashboard dan ekspor Excel; ekspor Dashboard tidak menyertakan baris rekening, mempertahankan nilai agregat, dan menggunakan indentasi satu spasi per tingkat hierarki.
- `/tautan` dan `/shortlink` menyajikan halaman publik gabungan **Tautan dan Pendekin**; URL lama memilih mode awal yang sesuai pada dropdown. `GET /api/link-directory` hanya menampilkan tautan aktif dalam topik yang aktif. API menyertakan ringkasan global topik dan tautan yang terlihat publik. Tanpa filter, API mengembalikan topik utama, hingga lima subtopik per topik, serta pratinjau tiga tautan terbaru per subtopik. Tanpa `q`, `topic_id` mengembalikan satu topik utama beserta seluruh subtopiknya dengan bentuk respons dan ringkasan global yang sama. `category_id` mengembalikan tautan aktif berpaginasi untuk satu subtopik; `alias` menyelesaikan alias kustom kategori ke halaman topik utama atau rincian. Alias harus 3–63 karakter huruf kecil, angka, tanda hubung, atau garis bawah dan unik tanpa membedakan kapitalisasi. URL alias yang baru dibuat menggunakan `/t/<alias>`; route lama `/tautan/<alias>` tetap disajikan agar tautan yang sudah ada tidak rusak. Pencarian dengan `category_id` dibatasi pada tautan subtopik, sedangkan `q` global mencari judul, deskripsi, tag, serta nama/deskripsi topik; `topic_id` membatasi pencarian ke satu topik utama. Ringkasan hanya ditampilkan pada halaman awal semua topik utama. Judul halaman topik mengikuti nama topik, dan breadcrumb dapat membuka `Tautan`, topik utama, atau rincian.
- `/admin/tautan` dan `/admin/shortlinks` menyajikan halaman admin gabungan dengan sidebar tetap dan dropdown untuk memilih panel Tautan atau Shortlink. Pada panel Tautan, alias custom wajib diisi saat membuat atau mengedit topik; form tidak meminta pilihan tindak lanjut setelah topik disimpan. Panel Shortlink dikelola mandiri dan tidak memiliki relasi kategori. API kategori mewajibkan `custom_alias` pada `POST/PATCH /api/admin/link-categories`; kategori lama yang belum memiliki alias tetap dapat dibaca dan diakses melalui ID, tetapi alias harus diisi ketika diedit. API tautan tetap memakai `GET/POST/PATCH/DELETE /api/admin/link-categories` serta `GET/POST/PATCH/DELETE /api/admin/links`; tautan mencatat tahun, waktu input, dan waktu update otomatis. Perubahan status memakai `PATCH /api/admin/links/<id>/status`.
- API mutasi topik/tautan memakai autentikasi admin dan CSRF. Semua admin dapat mengelola topik serta mengubah status tautan; hanya pembuat yang dapat mengedit atau menghapus rincian tautannya.
- Penghapusan topik juga menghapus rincian dan tautan di dalamnya secara permanen. Jika topik memiliki isi, `DELETE /api/admin/link-categories/<id>` memerlukan JSON `{"confirm_contents": true}`; jika ada tautan milik admin lain, seluruh penghapusan ditolak dengan 403. Tanpa konfirmasi, topik berisi ditolak dengan 409.
- Topik lama dan topik baru berstatus aktif secara default. `PATCH /api/admin/link-categories/<id>/status` mengubah status topik tanpa mengubah status rincian atau tautannya. Topik nonaktif dan isinya tidak terlihat di direktori, pencarian, URL langsung, dan ringkasan publik; saat diaktifkan kembali, status isi yang sebelumnya tetap berlaku. Ringkasan admin tetap mencakup seluruh status.
- Migrasi startup menambahkan kolom status untuk topik lama. Backup database sebelum deployment, lalu rilis frontend dan backend bersama dan mulai ulang backend agar migrasi berjalan.
- Topik rincian yang masih memiliki tautan tidak dapat dijadikan topik utama. Tahun tautan lama yang belum diketahui tetap kosong; migrasi tidak lagi menyimpulkan tahun dari tanggal publikasi.
- `/admin/statistics` menyajikan statistik admin. `GET /api/admin/statistics?period=year|month|week|day|hour` memerlukan autentikasi admin dan mengembalikan hitungan halaman publik serta API publik, seri waktu UTC, dan maksimal 10 route teratas. Jendela menggunakan 365/30/7 bucket harian, 24 bucket per jam, atau 60 bucket per menit; statistik menghitung request, bukan pengunjung unik, dan tidak menyimpan IP/query string/payload. Tabel request menyimpan agregat route per menit, jam, dan hari; cleanup periodik mempertahankan sekitar 25 jam menit, 8 hari jam, dan 366 hari harian.
- Mode Shortlink pada halaman `/tautan` dan `/shortlink` menyediakan form anonim dengan token form bertanda tangan yang terikat sesi, waktu minimum pengisian, honeypot, dan batas 10 pembuatan per sesi per jam. `POST /api/shortlinks` menerima URL HTTP(S), alias huruf kecil 3–63 karakter, dan judul; masa berlaku opsional dapat diatur admin. Redirect publik menggunakan `/s/<alias>`: alias aktif mengembalikan 302 dan menghitung klik, alias nonaktif/tidak ada mengembalikan 404, serta alias kedaluwarsa mengembalikan 410.
- Bagian Shortlink pada halaman `/admin/tautan` dan `/admin/shortlinks` menampilkan ringkasan status serta pasangan jumlah dibuat/diklik per tahun dan menyediakan form pembuatan untuk admin. Daftar menyertakan waktu dibuat dan diupdate. Endpoint yang digunakan adalah `GET /api/admin/shortlinks/summary`, `GET /api/admin/shortlinks?q=&limit=&offset=`, `POST /api/admin/shortlinks`, `PATCH /api/admin/shortlinks/<id>`, `PATCH /api/admin/shortlinks/<id>/status`, dan `DELETE /api/admin/shortlinks/<id>`. Endpoint admin memakai autentikasi dan CSRF; seluruh admin dapat mengelola shortlink. Klik disimpan sebagai agregat per shortlink per tahun, dan penghapusan permanen juga menghapus agregat klik.
